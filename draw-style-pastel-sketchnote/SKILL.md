# 柔彩速写笔记（Pastel Sketchnote）

**范围**：只规定颜色、线条、字体、图标、装饰等视觉语言。**不**规定分栏、步骤、网格、辐射等布局；结构跟用户内容与工具自由发挥。

## 何时读参考

- 对齐画风 → 读 [references/style-reference.md](references/style-reference.md)，按需查看 `assets/samples/` PNG
- 色值与用色习惯 → 读 [references/palette.md](references/palette.md)

## 工作流

1. **理解内容**：自行决定最合适的排版或用户指定。
2. **套视觉**：奶油底、手绘墨线、大圆角、柔彩填色、线稿图标；色值见 palette.md。
3. **可选校准**：打开 `assets/samples/` 任一张图，只核对线条/配色/字体气质，不抄构图。
4. **自检**：用下方清单；文生图则套提示词模板。

## 风格要义

读者应感到「有人在白板上认真画笔记」，而不是企业 PPT 或 CAD。

- **手绘线**：略抖墨线更亲切；完美矢量线偏冷硬。
- **奶油底 + 柔彩块**：低饱和色块辅助扫读；参考图只校准色感与饱和度。
- **大圆角 + 留白**：信息密时加间距，而非缩小字号。
- **线稿图标**：可辨即可，避免写实插画压过正文。

## 30 秒速查

| 维度 | 规范 |
|------|------|
| 画布 | 奶油白 `#FFF9F0`，可选点状外框 |
| 描边 | 墨线 `#1E293B`，约 2px，略带手绘抖动 |
| 圆角 | 12–20px |
| 边框 | 实线 + 虚线子框可并用 |
| 箭头/连线 | 手绘感，灰 `#475569` 或淡青 `#7DD3FC` |
| 避免 | 渐变、霓虹、3D、冷蓝工程图默认风 |

## 出图前自检（仅视觉）

- [ ] 奶油底、无渐变
- [ ] 填色 ≤5 种，低饱和柔彩
- [ ] 圆角、留白、手绘墨线
- [ ] 线稿图标风格统一
- [ ] 标题/正文层级清晰；关键词可用 pill
- [ ] 未误用冷色精确工程风

## draw.io / 画板

- 圆角 ≥12，线宽 2，颜色见 palette.md
- 连接器可曲线；箭头小而圆钝
- 布局由用户定；本 skill 只约束视觉参数

## 与冷色技术风

| | 本 skill | `draw-style` 冷色技术风 |
|--|----------|-------------------------|
| 线 | 手绘微抖 | 精确 2px |
| 色 | 奶油 + 柔彩 | 冷蓝青绿靛 |
| 布局 | 不规定 | 不规定 |
| 场景气质 | 教程笔记 | 工程博客 |

用户明确要冷色精确风时才切换；否则用本 skill。
