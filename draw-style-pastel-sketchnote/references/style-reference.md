# 视觉参考（不含布局）

`assets/samples/` 内 PNG 仅用于对齐**画风**，不要照搬其构图、分栏或步骤结构。排版由用户内容与任务自行决定。

## 从参考图提取什么

打开任意一张或多张样例，只校准下列视觉要素：

| 要素 | 观察要点 |
|------|----------|
| 线条 | 墨线略抖、约 2px、非 CAD 直线 |
| 底色 | 奶油白 `#FFF9F0`，无渐变 |
| 填色 | 低饱和柔彩块，同图种类少 |
| 容器 | 大圆角；实线外框 + 虚线子框可并存 |
| 字体 | 手写/圆体标题 + 清晰正文；关键词 pill |
| 图标 | 简约线稿，少量平涂 |
| 装饰 | 星标/放射线稀疏；便签/胶带可选 |
| 气质 | 友好教程笔记，非冷色工程图 |
