# 风格参考图（非布局模板）

共 7 张风格参考 PNG + 3 张 badcase。用途：**对齐线条、配色、字体、图标气质**；不要照搬图中的分栏、步骤或构图。

- `badcase-arrow-line-too-short.png`：连线被压得过短、三角与结构线堆积。
- `badcase-text-low-contrast.png`：深灰字 + 深底，对比不足看不清。
- `badcase-connector-circuitous.png`：连线迂回 U 折、穿过框内文字。

说明见 [references/style-reference.md](../../references/style-reference.md)。

从仓库根 `local/` 更新后：

```bash
cp local/*.png draw-style-pastel-sketchnote/assets/samples/
```
