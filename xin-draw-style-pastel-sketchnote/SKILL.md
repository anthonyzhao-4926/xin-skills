# 柔彩速写笔记（Pastel Sketchnote）

**范围**：只规定颜色、线条、字体、图标、装饰等视觉语言。**不**规定分栏、步骤、网格、辐射等布局；结构跟用户内容与工具自由发挥。

## 何时读参考

- 对齐画风 → 读 [references/style-reference.md](references/style-reference.md)，按需查看 `assets/samples/` PNG
- 色值与用色习惯 → 读 [references/palette.md](references/palette.md)

## 工作流

1. **理解内容**：自行决定最合适的排版或用户指定。
2. **套视觉**：奶油底、手绘墨线、大圆角、柔彩填色、线稿图标；色值见 palette.md。
3. **可选校准**：打开 `assets/samples/` 任一张图，只核对线条/配色/字体气质，不抄构图。
4. **自检**：用下方清单；文生图则套提示词模板。

## 风格要义

读者应感到「有人在白板上认真画笔记」，而不是企业 PPT 或 CAD。

- **手绘线**：略抖墨线更亲切；完美矢量线偏冷硬。
- **奶油底 + 柔彩块**：低饱和色块辅助扫读；参考图只校准色感与饱和度。
- **大圆角 + 宽松间距**：元素之间留足空隙，宁可少放一块或拆图，也不要挤成一团（见「元素间距」）。
- **线稿图标**：可辨即可，避免写实插画压过正文。

## 30 秒速查

| 维度 | 规范 |
|------|------|
| 画布 | 奶油白 `#FFF9F0`，可选点状外框 |
| 描边 | 墨线 `#1E293B`，约 2px，略带手绘抖动 |
| 圆角 | 12–20px |
| 间距 | 相邻元素 ≥24px，框内边距 ≥12px；勿拥挤（见下） |
| 边框 | 实线 + 虚线子框可并用 |
| 连线 | 手绘感，灰 `#475569` 或淡青 `#7DD3FC`；**留足线段与间距**，勿压成短线（见下） |
| 避免 | 渐变、霓虹、3D、冷蓝工程图默认风 |

## 元素间距（勿拥挤）

整张图应**疏朗可读**；参考 `assets/samples/` 风格样例里的留白感，不要为塞内容把卡片、文字、图标压在一起。

- **相邻色块/卡片**：外缘间距 **≥24px**（横向、纵向同一标准）；并排三格以上时也不要小于此值。
- **框内边距**：文字与边框 **≥12px**；多行条目之间 **≥8px** 行距。
- **画布留白**：主内容区距画布边缘 **≥24px**；标题区与正文区之间 **≥16px**。
- **装不下时**：删减条目、拆成两张图或缩小范围——**优先减内容或扩画布**，不要同时缩小字号、压缩间距、缩短连线。
- **禁止**：卡片贴贴、文字贴边、图标压字、多个元素共享同一条边线无空隙。

## 连线与箭头

连线需要**呼吸空间**。元素间距不足时，线段会被压成一小截，箭头与标签也会堆在一起（badcase：`assets/samples/badcase-arrow-line-too-short.png`）。

### 连线留白（通用）

- **与元素间距配合**：有连线的两容器之间，间距至少满足上文 **≥24px**；底线 **≥16px** 仅作极端情况，常规应更宽。
- **可见线段**：任意一段竖/横向连线，可见长度 ≥ **24px**；多段折线在每段转角后仍保留可见直线，不要「零长度拐角」。
- **贴边出口**：连线从框边引出后，先走 **≥8px** 再转弯或挂标签，避免贴边即折、贴边即画三角。
- **禁止**：为省空间把连线压到几乎看不见；连接点直接压在分隔线、边框或另一元素上。

### 走线方式（勿迂回折叠）

连线走**最短、最直白的正交路径**，不要绕远、折返或 U 形兜圈（badcase：`assets/samples/badcase-connector-circuitous.png`——线先上再右再 U 转，穿过框内文字）。

- **优先**：相邻框之间 **1 折（L 形）或 2 折** 即可到达；水平相邻用横线+垂线，垂直接邻用竖线+横线。
- **入口**：从源框**朝向目标的一侧**出线（如目标在右侧 → 从源框右侧出），从目标**朝向源的一侧**入；避免从顶绕一大圈再从侧面钻入。
- **避障**：连线走在**元素之间的空隙**，不要横穿色块内部、不要压过正文/标签。
- **禁止**：无必要的 180° 折返、绕到目标外侧再折回、折线数 >3 仍可到却绕路；为躲障碍而把线塞进文字区。

### 箭头（在通用规则之上）

- **箭杆**：除三角外须有够长箭杆（≥ **24px** 或 ≥ 三角高度 **2 倍**）。
- **落点**：三角指向目标区域，与结构线、平行边框保持 **≥8px**，勿与横线/虚线重合。
- **禁止**：只有三角没有杆；三角骑在上下结构线上。

## 文字与底色对比

字色必须与底色**明显分离**，否则标签、pill、色块内文字会糊成一团（badcase：`assets/samples/badcase-text-low-contrast.png`——深灰字压在近黑底上）。

- **浅柔彩底**（薄荷/天蓝/淡黄等，见 palette.md）：正文与标签用 **墨线字 `#1E293B`**，不要用中灰 `#64748b` / `#94a3b8` 当主字色。
- **深色底**（墨线 `#1E293B` 或更深）：字用 **`#FFFFFF` 或奶油 `#FFF9F0`**，禁止深灰字上深底。
- **pill / 小标签**：要么「浅底 + 墨线字」，要么「深底 + 白字」；避免「深底 + 深灰字」。
- **自检一眼**：眯眼或缩略图仍能认出每个词；连线旁、箭头上的短标签同样适用。

## 出图前自检（仅视觉）

- [ ] 奶油底、无渐变
- [ ] 填色 ≤5 种，低饱和柔彩
- [ ] 圆角、手绘墨线；元素间距疏朗（相邻 ≥24px，框内 ≥12px）
- [ ] 线稿图标风格统一
- [ ] 标题/正文层级清晰；关键词可用 pill
- [ ] 未误用冷色精确工程风
- [ ] 连线未被压短：元素间 ≥16px，可见线段 ≥24px，无贴边零长度折线
- [ ] 走线简洁：无迂回 U 折、不穿过框内文字，正交 L/之 形为主
- [ ] 箭头有够长箭杆，三角未与框线/分隔线堆叠
- [ ] 色块/pill/标签上字与底对比足够（浅底墨字 / 深底白字）

## draw.io / 画板

- 圆角 ≥12，线宽 2，颜色见 palette.md
- 分布/对齐时保持卡片间距 ≥24px、框内边距 ≥12px，再布线
- 优先正交直线，少用自动绕路
- 手动调整拐点，避免 U 形折返与穿框；入口选在朝向对侧
- 箭头小而圆钝；拉长线段再挂三角，连接点勿贴在分隔线或边框转角上
- 色块填字：浅填充配 `#1E293B`，深填充配 `#FFFFFF`；勿深灰字加深底
- 布局由用户定；本 skill 只约束视觉参数
