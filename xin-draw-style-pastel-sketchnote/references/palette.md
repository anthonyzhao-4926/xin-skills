# 色板与用色习惯

## 填色（同图 ≤5 种）

| 名称 | 十六进制 | 常见语义（可按内容调整） |
|------|---------|-------------------------|
| 薄荷绿 | `#E2F0D9` | 正向、推荐 |
| 浅珊瑚 | `#FAD7D4` | 警示、反例 |
| 天蓝 | `#D9EAF7` | 工具、说明 |
| 淡黄 | `#FFF2CC` | 强调、要点 |
| 薰衣草 | `#EDE9FE` | 次要信息 |
| 蜜桃 | `#FFE4D6` | 补充、过渡 |
| 标题蓝条 | `#B8D4E8` | 标题条（可选） |

## 基础

| 名称 | 十六进制 | 用途 |
|------|---------|------|
| 奶油底 | `#FFF9F0` | 全图画布 |
| 墨线/正文 | `#1E293B` | 描边、**浅底上的主文字** |
| 反白字 | `#FFFFFF` | **深底上的文字** |
| 连线灰 | `#475569` | 箭头、连接线（不作色块内正文） |
| 强调青 | `#7DD3FC` | 可选流向高亮 |

## 文字与底色配对（必守）

| 底色类型 | 字色 | 禁止 |
|----------|------|------|
| 浅柔彩块、pill、奶油底 | `#1E293B` | 中灰 `#64748b` / `#94a3b8` 作主字 |
| 墨线深色块、近黑标签 | `#FFFFFF` 或 `#FFF9F0` | 深灰字上深底 |

badcase：`assets/samples/badcase-text-low-contrast.png`（深灰「并行」贴在近黑底，无法辨认）。

## 用色习惯

- 同图保持低饱和、种类少；相邻色块对比柔和即可。
- 淡黄适合点缀标题或短句，避免整页大面积铺黄。
- 色块语义随内容而定，样例图中的绿/珊瑚搭配仅供参考色感，非强制布局套路。

## 字体层级（等效像素）

- 主标题：24–32，粗手写/圆体
- 分区标题：比正文粗一级，可加色条
- 正文：11–14，行距宽松
- 关键词 pill：浅底 + 墨线字，或深底 + 白字；**勿**「略深柔彩底 + 中灰字」

## 图标与装饰

- 线稿图标：文档、终端 `>_`、盾、书、机器人、夹、齿轮、钩子等
- 装饰稀疏：星标/放射线（标题旁 1–3 处）、便签/胶带/爱心（0–1 处）

## 禁止项

渐变、霓虹、高饱和红黄橙主色、1px 科技线、3D 阴影、照片写实背景、**低对比字色**（深灰字 + 深底）。
